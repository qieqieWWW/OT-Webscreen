## Installation and Usage

If you want to use the mod on a Mac, make sure it has an Apple Silicon chip rather than an Intel chip.

The complete installation and usage guide is included in the packages on the [Releases](https://github.com/qieqieWWW/OT-Webscreen/releases) page. Windows uses BepInEx 5, and Apple Silicon Mac uses BepInEx 6; the installer checks for and installs the corresponding version.

## Main Features

- Place, move, rotate, and resize a shared web screen in the room, and open web links.
- Use input mode to interact with web pages; URLs, mouse actions, and keyboard actions are synchronized within the room.
- Keep watching after collapsing the control panel; enter “Out-of-Body” mode to move your viewpoint freely or jump to the best viewing position with one click.

Each player's browser loads web content separately. Playback depends on each player's network connection and access to the website; the mod only synchronizes actions.
